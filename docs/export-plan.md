# 活動紀錄匯出規劃

## 目前狀態

此文件保存後續匯出需求. 目前活動紀錄, CSV 與圖表圖片尚未提供匯出操作. 使用者偏好設定的 JSON 匯入 / 匯出已實作, 見 [設定檔格式](settings-format.md)

## 預定內容

| 格式 | 內容 |
| --- | --- |
| JSON | 版本化 snapshot, 來源與時間區間, 分類, nullable metadata 與設定 |
| CSV | 對話, 工具 / MCP, Git, Skills / 驗證, 檔案修改與網路參考分開輸出 |
| 圖表圖片 | 目前圖表與選定的時間 / 間隔 / 刻度設定 |
| Markdown | 工作摘要, 個別工具文件與資源連結 |

使用者可選擇目前篩選結果, 指定區間或全部已載入紀錄, 列出匯出範圍, UTC 與顯示時區, 已知 / 缺漏資料, chart 設定及產生版本. 匯出時固定 snapshot, 避免更新週期造成跨表數據不一致

## 資料格式與擴充

- 保留 `source`, 原始 server / tool 名稱, category, timestamps, Call ID 與來源識別
- 未知值以 JSON null 或 CSV 空欄輸出, 不將畫面 `--` 當作資料
- 新來源使用通用欄位, 額外摘要放 namespaced metadata. schema 新增欄位可相容, 意義變更需更新版本
- 設定檔沿用已實作的 version 1 匯入 / 匯出. 活動匯出可附帶選定設定, 匯入仍先驗證並預覽覆蓋範圍
- 動態分類與自訂工具用途保存原始識別名稱, 換電腦後只有可取得的來源參與觀察

## 資料邊界與效能

預設匯出目前可觀察的 metadata. credential, prompt, 原始命令與未經選取的工具 payload 不進入匯出. Jev payload 與完整檔案位置如需匯出, 提供明確的選擇與預覽

大範圍分批產生, 顯示進度, 支援取消. CSV 防止公式注入, 檔名由程式產生並限制下載為本機連線. 匯出不自動開啟新 collector 或執行 provider API

## 後續驗收

驗證未知值, 時區, 新來源 / 新欄位, 特殊字元, 資料去重與多表一致性. 以小量 / 大量 fixture 驗證記憶體與取消行為, 再驗證瀏覽器下載與設定附帶匯出
