# LAM 1.0.0 前補齊與驗收規劃

日期 2026-10-07, 此規劃只涵蓋 Local Activity Monitor. Workbench UI 的元件、API 與瀏覽器驗收由該儲存庫獨立核對, 通過共用元件測試不代表 LAM 的資料來源、保存或啟動流程已通過

## 獨立核對順序

1. 以 LAM 最終 diff 選擇 focused Python / JavaScript 檢查, 先驗資料及設定規格
2. 以隔離的合成 Codex home / DB 操作本機 Web 頁面, 驗證來源、卡片與表格流程, 記錄 console / network 及取消結果
3. 使用實際核准的 Workbench UI revision 重驗串接, 共用庫發布與 LAM pin 更新分開處理
4. 核對平台與發布邏輯, 本輪依使用者限制執行最小檢查, 不建置本機免安裝包
5. 每項記為通過、失敗、未執行或未驗證, 必要門檻尚未通過時不宣告 1.0.0 可發布

## 後續資料功能, 本輪不實作

| 項目 | 待核對與設計 | 驗收條件 |
| --- | --- | --- |
| 對話 table 名稱 | 核對正式標題、來源優先序、背景 / 子代理工作及未命名 fallback. 目前截圖出現完整工作指令, 不直接把指令當成正式名稱 | 改名與重載一致, 合成主對話 / 子工作 / 無標題資料, 不額外讀取私人 prompt 產生名稱 |
| 單位時間 Token 量 | 以同一來源、同一對話的相鄰累計值及觀察時間計算差額, 可提供 Token / 分鐘, 輸入、輸出、快取分開標示. 視窗、時間戳與樣本數需可辨識 | 缺值、無後續樣本、重複 / 亂序資料、非正時間差、計數重設保留未知, 不以總量除以對話時間, 不重複計入快取 |
| 對話 / 行為消耗排行 | 放在「用量與額度」頁, 對話排行與行為排行可切換, 依總量、輸入、快取、輸出或估算金額排序, 連到所屬對話與行為 modal | 只用已觀察的來源欄位或可確認的差額, 保留資料涵蓋範圍與歸屬方式. 不把外層 exec 用量分配給內嵌工具, 不重複加總父子行為與對話累計 |
| 行為明細 modal | 列出所屬對話、來源 / 模型、行為識別、開始 / 結束、耗時、結果、輸入、輸出、Token 分項、速率及估算費用. 輸入 / 輸出提供解析、原文、sticky icon 複製與框內全選 | 原文沿既有允許路徑 / 大小 / 遮蔽規則按需取得, 不持久保存或放進排行快照. 缺值與零值分開, 單次行為 / 外層工具 / 對話資料清楚標示, modal 關閉後中止要求並回收 |
| Token / cached Token 費用估算 | 在同頁提供共用估算摘要, 對話及行為 modal 顯示分項. 報價依 provider、計費來源、模型、處理等級及長短上下文規則選取, 保存官方來源 URL、核對時間、幣別 / credits 單位及報價版本 | 不重複計入 cached input 或已包含在 output 的 reasoning. 未知模型 / 缺欄位 / 不明處理等級保留未知或明示估算假設, 不以 API 價格表示訂閱實際扣款. 使用精確小數, 驗證報價更新與歷史估算重算 |
| 批次資料查詢 | 排行、速率與費用估算可依共同時間範圍、對話 / 行為 ID、來源與模型批次取得統計及 metadata, 去重後共用讀取與聚合, 報價使用同一版本 | 明確限制 ID 數量、時間範圍、回應大小與並行數, 支援分頁 / 分批、取消及逐項結果. 空 ID 清單不代表全查, 缺失 / 失敗項目不補成零, 舊回應不覆寫目前篩選 |

Token / 分鐘表示觀察區間的活動速率, 包含等候與工具操作時間, 不等同模型生成速度. 模型輸出 Token / 秒需要來源提供相符的生成起迄時間, 目前是否可取得仍待核對. 現在 Codex collector 保存每個對話的最新累計值及時間, 尚未提供行為歸屬與完整速率樣本, 後續需另設有界樣本及保存期限. 以上由 LAM 管理資料語意與報價, 共用 table / modal / 圖表的布局與元件行為由 Workbench UI 管理

2026-10-07 核對 [OpenAI API 報價](https://developers.openai.com/api/docs/pricing) 與 [Codex 計價](https://learn.chatgpt.com/docs/pricing#token-rates). API 金額與 Codex credits 分開估算, 不假設 credits 有固定通用的美元換算. 一般文字計價將非快取輸入、快取輸入與輸出乘上各自每百萬 Token 單價後相加, 有獨立 cache-write 計價時另依模型規則計算. 快取寫入、工具費用或其他計價欄位無資料時標示未涵蓋, 不能假設完整金額已算出

報價擷取不傳送對話或輸出內容, 儲存有版本的本機價目表, 提供更新時間、過期提示與手動覆寫. 明確區分「依當時報價」與「依目前報價重算」, 不把查價失敗當成零元

批次 API 由 LAM 管理, 使用固定欄位與受限查詢參數, 不接受任意 SQL 或檔案路徑. 同一批次標示快照時間、資料涵蓋範圍與報價版本, 排行依指定範圍的完整統計計算, 不只排序目前分頁. 大批資料分段及按需載入, 不同時啟動所有查詢造成 peak. 快取需有容量、保存期限與更新失效條件, 合成資料驗證不同批次大小的讀取量、CPU / 記憶體與取消清理. 輸入 / 輸出原文仍在 modal 按需取得, 不隨統計批次大量載入

## 本輪仍待的發布證據

目前操作證據使用 Edge 與合成資料. 原生 macOS、Safari / iPad、平台 WebView、完整輔助技術、真實使用者來源與長時間更新仍需各自驗收. 沒有同條件基準的效能項目列未知, 不以功能通過推論 peak 或記憶體已改善

詳細來源及檢查方式見 [資料清單](data-inventory.md)、[維護檢查](maintenance.md)、[驗證紀錄](validation.md). 此文件不變更版本、pin、發布設定或使用者存檔
