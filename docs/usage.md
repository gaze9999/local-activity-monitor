左上顯示 LAM 名稱與版本, 右上顯示 LAM / Codex 狀態, 更新時間, 更新頻率, 啟動時間與執行時間. 主頁上方預設提供四項摘要, 數量與項目可自訂, 子頁不設摘要, 細節依用途放在子頁與明細. 對話子頁與 MCP 來源按鈕自動換行. 主頁右上統一提供來源範圍與設定齒輪, 子頁用途可從 Tab tooltip 查看. 各主頁最下方列出資料來源, 讀取方式與範圍

點對話列開啟明細, 聚焦後也可按 Enter / Space. 對話名稱與該列使用同一入口, 不放重複按鈕. 連到不同明細的關聯對話與工具使用按鈕. Popup 支援返回上一個明細, 切換明細子頁時回到內容頂端. 可用 Esc, 外側或關閉按鈕關閉

MCP 來源選擇固定展開並自動換行. 呼叫排行預設隱藏, 啟用時顯示前 5 名, 操作表格依選定來源與範圍顯示, 來源明細保留使用統計. 主頁及子頁切換保留頁面捲動位置, 明細視窗的 Tab 切換回到內容頂端

對話可依來源實際提供的模型篩選. 推理等級使用不同顏色, Log 等級保留英文 error / warn / info / debug / trace 等來源值, 並以顏色區分

狀態標籤在列表與明細一致: 執行中為藍色, 已完成為綠色, 錯誤 / 失敗 / 逾時為紅色, 等待中 / 排隊中為黃色, 回補中為紫色. 其他狀態維持中性色. 文字標籤保留, 指向可查看最近確認時間與回補狀況

缺少數值或來源未提供的欄位顯示 `--`, 已確認為零的計數顯示 `0`, 已確認沒有錯誤顯示"無". Model 與推理等級依最新設定事件合併, 缺少時使用本機 catalog 可提供的值. 明細列出資料與狀態來源

## 對話追蹤與狀態

設定的更新與追蹤可調近期 session 數量 (1 - 5000, 預設 20), 或追蹤全部, 上限 5000. 每輪 session 讀取共用 8 MiB 預算, 初次讀取頭行與最多 1 MiB 尾端, 之後增量讀取

狀態取自 `task_started` / `task_complete`, 缺少時優先反向回補工作事件. 最近確認的狀態與讀取位置採循環保存, 程序重啟後可沿用. 程式停用期間若有未涵蓋的紀錄, 保留最近狀態並繼續回補, 明細與 tooltip 顯示來源與確認時間. 不以對話建立時間推估工作耗時

Skills 保存最近 500 筆選定讀取 metadata, 依 Thread ID, Call ID 與 Skill 去重. 重新整理與重新啟動保留此範圍的計數. Skills 讀取不等同已使用. 重啟後尚未重新觀察檔案路徑的紀錄保留讀取次數, 仍可開啟 metadata 明細, 文件內容需有可讀取的來源路徑

純 ChatGPT 雲端對話由本機 catalog 提供名稱, 時間與分類. 若 catalog 有 Model, 推理等級與 async status 就讀取. 沒有 session 或來源未提供的 Token / 工具次數維持 `--`

## 表格與排序

各頁與表格的篩選區預設收合, 可展開 / 收合, 收合時保留條件並列出已套用數量, 狀態保存在目前瀏覽器與設定檔

表格齒輪可設定每頁筆數, 排序欄位, 方向, 顯示欄位與欄位順序. 先排序完整篩選結果再分頁, 缺值置後. 頁碼可按 Enter 或離開欄位套用, 自動更新保留正在輸入的頁碼

所有表格預設全寬並展開, 可從標題收合. 展開選擇與排序保存在目前瀏覽器及設定檔, 副標題與篩選位於展開內容中. 表格齒輪與標題同列. 預設優先依時間, 再依數量等數值由大到小, 其餘依字母排序, 操作欄位省略排序入口

桌面多欄表格在表格範圍內橫向捲動, 表頭隨內容捲動, 不使用浮動表頭. 760 px 以下改成帶欄位名稱的資料卡. 選擇全部對話時每批建立 50 列, 捲動或按載入更多後再增加

數值熱度預設關閉, 可在全域顯示設定啟用, 個別表格可覆寫. 以目前頁面顯示的資料逐欄比較, 顏色越深代表數值越大. 僅套用已知數值, 不將 ID, 日期或缺值當成數值

右上"拖曳排序"預設關閉. 開啟後可直接拖曳主 / 子 Tab, 表頭, 圖表標題, 活動摘要與其他頁面的卡片標題. 不顯示握把圖示, 各區域獨立排序, 頂部主要數值卡不參與. 拖曳時有浮動預覽與插入位置提示, 靠近邊緣會捲動

Tab / 表頭可用 Alt + 左右方向鍵調整. 垂直項目與卡片標題可用方向鍵 / Home / End. Modal 內不提供拖曳排序, 主頁排序開關只作用於外部元件. 關閉拖曳開關時排序快捷鍵也停用. 順序使用原始識別保存, 自訂文案不改變對應. 新項目接在保存順序尾端

## 圖表與統計

各圖表齒輪調整時間範圍, 起訖, 間隔, 顯示項目與數值上限. 趨勢提供長條 / 折線. 分布提供橫條, 直條, 堆疊直條, 圓餅與環圈. 有完整分類時顯示分段, 缺少時保留未分類總量

總覽 Tab 設定可選顯示與排序, 與下方活動摘要分開. 可加入 Git, 技能, 驗證, My dots, 網路, 錯誤, 資料更新耗時與讀取量等圖表. 卡片庫列出各圖表可切換的形式, 固定形式的卡片維持其預設

各頁的圖表與一般資訊卡依顯示數量排列: 一張使用全寬, 兩張分兩欄, 三張以上分三欄. 相鄰圖表區塊合併排列, 卡片接續填入較短的欄位. 總覽圖表維持四欄. MCP 資料來源與活動摘要等小卡沿用較密集的排列, 窄螢幕逐步改為單欄

直條與趨勢圖包含刻度, 單位與格線, 0 上限代表自動. 自訂上限低於峰值時圖形截短, tooltip 保留實際值. 分布圖的總量與圖例放在圖形外, 避免長數值擠壓環圈中心. 直條標籤依實際字體與可用寬度判斷, 需要傾斜時整組一致傾斜. 太長保留省略號與完整 tooltip

耗時與時間趨勢提供平均值, P99, Low 1% (P1) 與含樣本數的統計範圍. 分類排行, Token 分布與額度快照不顯示這些統計. P99 / P1 使用線性內插, 分別表示第 99 / 1 百分位數. 耗時與 CPU 使用有效樣本, 活動趨勢包含零活動時間格

圖表資料取自目前載入紀錄. 模型 / 執行位置 / 活動來源依對話最近活動時間篩選, 工具依呼叫時間篩選. 趨勢最多 240 格, 長區間自動放大間隔. 滑鼠或鍵盤可查看數值, 趨勢圖支援左右 / Home / End

## 用量, MCP 與 My dots

用量頁列出本機已取得的方案, 額度視窗, 剩餘比例, 已使用比例, 重設時間與 credits. 進度條顯示剩餘量, 到達重設時間後等待來源更新. 不隨時間推估額度. Token 分析採每個 thread 最新累計值, 不重複加總歷次快照, Cached input 與 Reasoning output 不再加進 Total

官方帳戶查詢位於主設定的監測項目, 預設關閉. 啟用前需有已登入的 Codex CLI, 不需另外輸入 API Key. 查詢結果至少快取 60 秒, 每次最多等待 10 秒, 回傳最多 1 MiB. 不支援或失敗時保留來源狀態, 不補零. 帳戶 Token 統計與已載入對話的 Token 分開呈現. 方案名稱只使用來源提供的值

MCP 來源由設定與載入的工具紀錄發現, 各來源有獨立子頁. 只有全部來源子頁列出完整來源卡片, 選單一來源時只列該來源操作. 用途優先取來源 description 或已設定 README, 可在設定修改. 有用途資訊時顯示, 缺少時省略用途區塊. 分類標籤依來源與工具名稱補充文件查詢, 搜尋, 資料庫, 瀏覽器等用途

各排行榜預設顯示前 5 項, 數量選擇集中在卡片右上角齒輪內. 各表格預設每頁 10 筆, 可在表格齒輪內調整. 全部來源排行包含所有已發現來源, 個別來源明細列出該來源工具使用統計. 圖表與摘要在上方, 表格集中在下方. 來源卡說明最多三行, 完整說明可從 tooltip 與來源明細查看, 無法取得的耗時統計省略

來源提供的指標依載入欄位分成用量, Credits 與費用, 耗時, 節省與壓縮, 瀏覽器與頁面, 驗證或執行結果. 列出選定數值與 boolean metadata, 包含用量, credits, 重試, 文件數與耗時. 一般指標保留最新值與時間, 耗時提供樣本數, 平均, P99 與 P1. 不將多個工具共用的 exec 回傳分配成個別結果. 程式碼辨識是呼叫位置, 不推估實際執行次數

MCP 標籤由用途, 工具名稱與回傳欄位推導, 可在設定搜尋來源並編輯最多 4 個標籤. 未知來源會自動加入觀察. 來源紀錄頁顯示實際紀錄狀態, 開關由來源管理, dashboard 不自動啟用紀錄

連線狀態使用本機呼叫, 回傳與傳輸錯誤, 列出最近回應時間與尚無回傳的呼叫數. 這項觀察不呼叫 MCP 或消耗額度

Jev 位於 MCP 子頁, 透過共用來源區塊顯示本機用量, HTTP 嘗試, 大小, 操作明細與活動紀錄. 未知的操作 / 狀態與符合單位規則的新增指標也會顯示. 來源紀錄範圍沿用全域值或本頁覆寫, 本機紀錄與操作列表一起套用. 指定呼叫明細才讀取可獨立辨識的送出 / 回傳, 遮蔽 credentials, 不另存內容. My dots 顯示已取得的產出類型, 時間與關聯對話. 來源提供名稱時套用, 缺少時使用 My dots

## 設定與說明

右上齒輪使用側邊分類, 包含外觀, 顯示, 更新與追蹤, 介面與說明, 監測項目, MCP 來源, 來源紀錄與設定檔. 小螢幕改成橫向導覽. 提供繁體中文, English 與日本語, 介面字級預設 14 px, 可調整為 12 - 18 px, 修改數字先保留草稿, 按套用才變更及保存. 另可設定主題與強調色. 更新頻率為 1 - 3600 秒, 數量 / 字級等設定四捨五入為整數. 既有有效偏好保留, 還原預設後套用新預設

介面與說明分工具說明, 介面設定與指標說明子頁, 有搜尋與分類篩選. 保留未儲存草稿, 逐列或整頁儲存. 有自訂內容才顯示還原預設, 文字以純文字處理, 每項最多 400 字元. 成功 / 失敗使用短暫浮動通知, 不改變頁面配置

Tooltip 共用樣式, 靠近右邊界時向左調整. 開啟 modal 後隱藏原提示, 關閉後不因恢復焦點再次彈出. 欄位, 統計, 圖表與設定皆可查看必要解釋. Esc 關閉

設定檔可匯出或選擇 / 貼上 JSON 匯入, 預覽確認後套用. 全部設定還原預設會先確認, 還原外觀, 語言, 顯示, 排序, 圖表, 表格, 文字與觀察設定. 已有活動紀錄保留. 保存欄位與上限見 [設定檔格式](settings-format.md)

## 錯誤與來源 Log

右上錯誤按鈕顯示最近 24 小時已載入錯誤數, 點擊直接篩選錯誤. 錯誤與來源 Log 使用子頁, 可依來源, 等級, 對話, 專案與工具篩選. Log 等級沿用 error / warn / info / debug / trace

錯誤明細提供原因分類, 時間, 模組, 錯誤類型 / 代碼, HTTP / exit code, Request / Trace / Call ID, 來源檔名 / 紀錄 ID, 可取得的原因與相關事件. 有關聯時可開啟對話或工具. 同一操作可能在不同來源各有紀錄

啟動時分批回讀既有 App / Core / session Log, 補上最近 24 小時可取得的錯誤. 選定錯誤摘要採循環保存, 網頁重整與程序重啟後保留. 程式自身只寫啟動, 設定, 失敗 / 恢復等少量事件. 詳細讀取範圍與資料邊界見 [錯誤觀察](error-observation.md)

## SQL, 網路, 檔案與 Skills

SQL 從工具參數, sqlite3 命令, literal Python SQLite 呼叫與 SQL 診斷辨識, 不執行來源程式碼. 點開操作明細才從對應的工具或診斷紀錄讀取 SQL 內容, 先遮蔽可辨識的憑證, 再以每頁 32,768 字元分批載入完整可取得內容. SQL 頁右上設定提供敏感資料遮蔽, 預設開啟, 來源沒有內容時顯示 --. 分開列出 SQL 診斷的個別耗時與整次工具耗時. 沒有可辨識紀錄時操作計數為 0. 來源沒記錄的 Codex 內部 SQLite 讀寫無法從此計數推知

網路提供操作, 網址與網站統計表, 點明細可查看參考時間與關聯對話. 移除 query / fragment, 排除 URL credentials 與內部 IP. 檔案從 literal 讀寫位置與 patch header 取得 metadata, 不展開變數或 glob

Skill 文件入口依目前已觀察路徑列檔案 metadata. Markdown / TXT / RST / AsciiDoc 可讀取並遮蔽 credentials, Python 等非文件只列資訊. 每次最多列 200 個檔案, 掃描 1000 個項目與 4 層目錄, 每份文件最多讀取 256 KiB

監測程式的耗時與 CPU 圖表提供平均, P99 與 P1. 最多 360 個效能樣本與 200 個執行事件. 瀏覽器隱藏時停止畫面輪詢, 後端仍收集. 各頁底部的資料來源與讀取範圍預設收合, 展開後列出當次讀取的實際位置, 欄位, 健康狀態, 上限, 保留量與回補進度. 個別來源可再次展開, 切換子頁時只列出相關來源. 關閉區塊時不建立詳細來源內容

資料來源詳細說明採全寬排列, 每個來源獨立展開, 最近更新時間在收合標題列持續顯示. 工具頁另有可篩選, 排序與分頁的工具統計明細, 直接呼叫與 exec 辨識分列, 沿用每頁 10 筆的預設

## 來源範圍與按需資料

全域來源紀錄預設最近 24 小時, 可改為 1 小時, 7 天或全部, 各主頁與對話 / 錯誤 / 專案活動子頁可獨立覆寫. 列表與操作統計一起篩選, 圖表範圍與表格條件在其中套用. 最新對話狀態, 累計 Token 與帳戶額度保留最近來源快照, 不因選擇短區間歸零. 沒有有效時間的事件只在全部範圍顯示

專案與子代理程式頁只列本機已載入的 metadata, 專案對話數及父子關聯受載入範圍限制. 專案圖示取來源已提供的欄位, 沒有時使用文字, 不另發送圖示請求

點專案才取得來源設定的資料夾, Global / Project AGENTS.md 另按需唯讀顯示. Git 操作明細才讀取對應的原始指令與回傳, 來源已不在可讀檔尾時可能缺值. 這些內容不加入平常快照或 checkpoint, 顯示前遮蔽可辨識 credentials, 不執行指令或文件內容

Skills 每列可開啟明細, 列表包括時間, 對話, Skill, 專案, 工具, 紀錄方式, 工具回傳時間, 耗時與 Call ID. JSON 或 literal 內容只解析成結構化顯示, 詳細內容預設收合

右上分別顯示 LAM 與 Codex 狀態, tooltip 列出狀態依據與時間. 監測程式的執行環境顯示處理器, 實體記憶體, GPU 型號 / 專用記憶體 / 共享上限 / 驅動版本, 可用記憶體留在已使用記憶體 bar 的 tooltip, 欄位值可折行, 左側標籤維持單行並可查看 tooltip. 對話內的指示文件, 技能文件與檔案操作明細提供本機檔案最後更新時間

總覽的活動圖表及活動摘要提供 tooltip, 可將游標移到標題或卡片, 也可用鍵盤聚焦查看說明

環境資訊依軟體環境, 作業系統, 處理器與記憶體, GPU, LAM 服務狀態分卡呈現. 多張 GPU 各自一張卡片, 資料保存資訊另列, 卡片順序在主頁調整
## 排行與明細

- 網路頁面提供參考網址與網站排行, 點擊圖表或統計列可查看參考時間, 對話, 網址來源與操作. 同一次工具操作中的重複網址合併計次, 網址保存頁面路徑, 移除查詢參數與 fragment
- 檔案頁面提供檔案與資料夾操作排行, 來源提供的讀寫量排行, 以及按需檢查的目前檔案大小排行. 排行沿用圖表的齒輪, 顯示數量與 tooltip, 詳細統計表放在獨立區塊
- 點開檔案可查看來源參數提供的行數, 頁面或位元組範圍, 讀寫量, 最後更新時間與關聯執行內容. 送出文字大小以 UTF-8 計算, 讀寫量使用來源的 `bytes_read` / `bytes_written`, 目前檔案大小在進入檔案頁時取得, 也可點擊更新
- 模型用量分析的圖表與表格均可開啟明細, 列出該模型的對話與最新累計 Token. 技能檔案由列表進入獨立檔案明細, 返回後保留列表位置
- MCP 來源的本地文件與設定置於來源子頁, 列出檔案位置與更新時間. 可編輯資料檔需通過格式檢查與版本比對才儲存, JavaScript / Python 設定與已遮蔽或截斷的內容提供唯讀檢視
- 工具與 MCP 的輸入, 輸出, JS 與 patch 由明細按需讀取. JSON, JSONL, TOML, XML, CSV / TSV 可解析為結構化資料, YAML 在來源已有相容解析器時提供解析與語法檢查

Codex 預設閒置五分鐘後暫停完整資料更新, 保留輕量活動檢查, 有新活動時恢復更新. 更新與追蹤設定可修改閒置分鐘數, 設為 0 可停用. CPU 使用量與已使用記憶體放在獨立裝置使用量卡片

SQL, 網路與 MCP 的選定活動 metadata 預設循環保存 7 天, 更新與重啟沿用已取得的紀錄. 設定可調整為 1 - 365 天, 縮短保留天數會移除已過期的摘要. SQL 最多 500 筆, 網路與 MCP 各最多 1,000 筆, 合計最多 1 MiB. 完整輸入與輸出只在明細開啟時取得

表格預設展開並使用全寬, 收合後顯示符合篩選的筆數, 有時間資料時補上最近時間. 檔案操作紀錄位於檔案頁的表格區最前方. 排行顯示檔名, 資料夾名或可區分的相對路徑, tooltip 顯示完整路徑

總覽將用量, 活動, 檔案操作與診斷等相近卡片排在一起, 帳戶用量與額度預設可見. 裝置使用量位於監測頁上方圖表區, 執行架構放在系統資訊. 資料保存與讀取量以多線折線圖呈現, SQL, 網路與 MCP 保存筆數分別置於對應分頁, 省略平均值與百分位數, 檔案趨勢可比較讀取與異動次數. 每條線有獨立圖例, 單位與樣本統計, 缺值不補零

頁面來源範圍預設仍為最近 24 小時, 要查看跨週末的活動可切換為 7 天或全部. 保存天數與顯示範圍分別設定, 已移除的摘要需有可讀取的原始來源才能重新取得

各分頁可從右上齒輪勾選要顯示的圖表與表格, 設定保存在目前瀏覽器並可匯入與匯出. 摘要項目與數量可個別調整, 相關分頁預設顯示三張圖表, 保留整體趨勢與多線比較, 次數排行及個別項目圖預設隱藏. 總覽提供其他分頁的全部圖表選項, 預設顯示 Model, 對話, 錯誤與用量, 系統監測與 My dots 預設隱藏. 總次數排行, 時間折線圖與統計表分開呈現, 技能, 工具, MCP, 網路網址與網站, 檔案與資料夾, Git 與驗證操作可按來源時間追蹤

檔案讀取次數與寫入及變更次數各有排行, 讀取量與寫入量另以 bytes 顯示. 大小資料取自來源回報的 bytes_read / bytes_written, 同次呼叫含多個檔案時需有可對應的個別大小資料. 操作次數, 送出文字大小與目前檔案容量分別計算

設定 switch 只在本體點擊時切換, 可用鍵盤操作. 啟用追蹤全部 session 後, 近期數量與套用按鈕停用. 套用到全部區塊若會覆蓋個別顯示數量或數值熱度設定, 先列出受影響的圖表與表格數量並要求確認, 取消保留原設定

網路活動紀錄置於網路頁的表格區首位. 裝置使用量卡片的更新時間位於右上角, 子頁與 modal Tab 和內容保留一致間距

對話表格的快取命中率以最新累計快取輸入 Token 除以輸入 Token, 保留可排序的百分比數值, 支援數值熱度. 缺少輸入量或輸入量為 0 時顯示 --, 已確認快取輸入為 0 時顯示 0%

共用[卡片庫](card-library.md)依來源分頁列出趨勢, 比較, 排行, 分布與獨立統計卡, 同列顯示可用的圖表形式與設定入口. 總覽中的卡片有自己的時間範圍, 顯示數量, 圖表形式及線數, 各來源分頁的設定保留獨立值. 多線圖預設 3 條, 可改為 5 或 10 條. 平均值, P1 / P99, 總數與統計範圍放在另一張卡片, bytes 取樣資料列出樣本數

主 Tab 摘要預設 4 張, 子 Tab 預設 3 張. 全域設定可調整為 1 - 8 張, 頁面設定可選擇項目, 編輯名稱及調整順序, 也可覆寫數量. 可顯示的數量受該頁已提供指標數限制, 不補上不存在的數值. 選擇沿用全域時, 後續全域數量變更會同步生效

Codex CLI (紀錄) 依載入對話紀錄的讀取順序去重, 先顯示 5 個版本, 點開全部版本可逐行查看. Markdown 文件提供預覽 / 原文切換, 支援標題, 清單, 表格, 連結與程式碼區塊. 預覽保留文字中的 HTML 原文, 圖片只顯示說明文字

按需內容先完成遮蔽再分頁, 取得範圍內沒有整體顯示字元上限. 工具, MCP, Git, SQL 與診斷內容以版本識別碼核對後續頁, 來源變更時提示重新讀取. 原始來源讀取範圍與身分檢查維持既有規則, 完整內容不加入活動快照或 checkpoint
