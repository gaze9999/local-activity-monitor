# 使用說明

## 頁面與明細

| 頁面 | 用途 |
| --- | --- |
| 總覽 | 對話, 工作時間, 工具與來源統計; 各功能摘要可點入對應 tab |
| 對話 | 名稱 / ID / 專案, 類型 / 位置 / 來源 tags, Model / 狀態, Reasoning 等級, tokens, 工具次數與工作總耗時 |
| 工具 | 工具排行, 用途與 exec 中辨識到的工具 |
| MCP | 來源與分類, 操作紀錄, 結果與摘要 |
| 網路 | 網路工具紀錄, 活動趨勢與參考網址 |
| 檔案 | 讀取 / 寫入 / 修改位置, 工具, 所屬對話, 時間與明細 |
| Jev | API telemetry, HTTP 嘗試 / 重試, tokens, 耗時及指定呼叫的送出 / 回傳 |
| Git 操作 | Codex 工具中的 Git 操作, 所屬對話與時間 |
| Skills | 讀取紀錄, 文件內容與腳本檔案資訊 |
| 驗證 | test / build / lint 與型別檢查操作 |
| 錯誤紀錄 | 對話送出失敗, MCP / 工具, 診斷警告與程式錯誤 |
| 程式狀態 | Runtime, 整理耗時 / CPU, 讀取量, 保存量與狀態事件 |

點對話列可開啟完整明細, 原本的 ID 與工具數量使用同一個入口; 明細內可繼續查看個別工具與用途, MCP 摘要, Jev 內容, 網路網址與檔案修改位置

Reasoning 等級取自最新 Model 設定紀錄, 缺少時使用本機 catalog 提供的值; 列表可篩選與排序, 新的等級名稱會自動列入選項. 明細依可取得的欄位顯示 Provider, Codex 版本, context window, 審核 / Sandbox 模式, 協作模式, Agent 與上層 Thread ID, 以及紀錄當時的 Git 分支 / commit; 欄位來源為 session metadata, turn context 或本機 catalog. Cache write input token 也可在明細查看

工作總耗時加總紀錄中可配對的 `task_started` / `task_complete`, 執行中的工作持續計時; 表格以秒顯示. 沒有起訖資料時顯示 `--`, 對話建立至最近更新的時間不當成工作耗時

表格缺值顯示 `--`; 明細與其他需要解釋的地方使用 "未知". "狀態未提供" 表示已有對話紀錄, 但沒有工作開始或完成事件

## 對話追蹤與載入

右上設定可輸入近期 session 數量 (1 - 5000, 預設 20), 或啟用全部追蹤. 每輪檔案讀取維持 8 MiB 預算, 全部追蹤最多 5000 個檔案, 會逐輪讀取

顯示選項預設 5 / 10 / 20 / 全部, 可在全域設定自訂 1 - 200 的最多 8 個選項, 排行預設 10 項, 表格預設 20 筆. 選擇全部時先建立 50 列, 捲動至底部或按 "載入更多對話" 後再增加 50 列; 搜尋或篩選變更後重新分批載入. 各表格右上齒輪設定每頁筆數或全部, 表格下方可輸入頁碼與切換上一頁 / 下一頁; 全部新表格預設 20 筆

表格欄位標題保持 sticky, 使用頁面或 popup 本身捲動; 窄螢幕或欄位數量超出可讀寬度時改成逐列區塊, 每個值旁保留欄位名稱. 區塊依可用寬度自動分欄, 只有一個圖表時填滿整列. 總覽的執行位置與活動來源各自一張卡片, 依內容高度排列, 圖表或字體改變後重新計算, 縮短欄間空白. 點欄位可切換升冪 / 降冪, 先排序完整的篩選結果再分頁; 紀錄預設依可取得的活動時間由新到舊, 缺值置後. 表格齒輪也可設定排序欄位與方向, 多選顯示欄位並拖曳握把改變欄位順序. 寬度足夠時可直接拖曳表頭; 目標位置顯示色線與前 / 後浮動提示. 表頭可用 Alt + 方向鍵, 設定握把可用方向鍵 / Home / End 移動; 卡片模式使用齒輪選擇排序. 新欄位自動接到已保存順序尾端, 排序使用原始欄位識別, 不受顯示位置或自訂文案影響

頁碼輸入後按 Enter 或離開欄位套用, 自動更新會保留正在輸入的頁碼

## 圖表

每張圖表右上角齒輪開啟專屬設定, 調整後即時更新:

- 時間範圍: 全部紀錄, 最近一段時間, 或指定起訖
- 最近時間: 輸入長度, 選擇分鐘 / 小時 / 天
- 時間趨勢: 選擇間隔與 Y 軸上限
- 排行 / 分布: 選擇顯示項目或全部, 長條圖可設定數值上限
- 座標軸上限: 0 代表自動; 小於資料峰值時截短圖形並顯示提示

齒輪左側按鈕循環切換圖表類型, 時間趨勢提供長條 / 折線, 排行與分布提供長條 / 環圈. 既有設定中的圓餅圖會改成環圈圖. 時間趨勢顯示座標軸刻度與必要單位, 實際時間間隔顯示在圖下; 刻度字體依區塊寬度調整, 保持可讀大小. 長條排行在右側顯示數量, 省略重複刻度, 長條隨區塊寬度延伸, 最大值自動填滿, 其餘依比例顯示. 環圈圖顯示數量與比例, 顯示項目以外的資料合併為「其他項目」, 滑鼠與鍵盤可查看數值. Jev 資料以小時彙整, 最小顯示間隔為 1 小時; 長區間最多建立 240 格, 超出時放大間隔

滑鼠指向長條可查看項目與數值; 指向趨勢圖可查看所在格的時間起訖與次數, 同時標出資料點. 折線與長條趨勢共用提示, 含 0 次的時間格也可查看; 鍵盤聚焦趨勢圖後可用左右方向鍵切換, Home / End 跳至頭尾

Model / 位置 / 來源分布依對話的最近活動時間篩選; 工具排行依工具呼叫時間篩選. 圖表統計使用目前載入的紀錄, 讀取範圍見 [程式架構](architecture.md)

## 設定與外觀

右上齒輪集中管理更新頻率, session 範圍, 觀察開關, 各來源分類與外觀. 更新頻率預設 10 秒, 可設 1 - 3600 秒; 字體可設 12 - 18 px. 顯示模式有跟隨系統 / 淺色 / 深色, 主題有工作台 / 簡約, 強調色有綠 / 藍 / 橘; 齒輪旁可直接切換 Dark mode

更新時間與每 X 秒更新顯示在右上角, 指向時間可查看完整日期. 二元設定使用 switch; 套用中, 成功與失敗會顯示在目前設定區. Tab 可拖曳握把調整順序; 聚焦握把後也可用上下方向鍵, Home / End 移動, 順序立即套用並保存. 全部還原順序會先確認. Popup 可用右上關閉圖示, Esc 或點外側關閉. 來源開關停用其摘要解析與顯示; 重新啟用後重新讀取選定 session 尾端

新 MCP 自動列出. 在設定中可將來源歸入文件 / OCR, 環境 / 驗證, Runtime / 瀏覽器, Codex 工作流程, Review / Security, 部署, App / 成果, Jev, 網路參考或其他 MCP; 已設定的來源標示 "已設定", 由 session 發現的來源標示 "有使用紀錄"

## 介面與說明設定

設定只有一個 "介面與說明設定" 入口, 以 "工具說明" 與 "介面設定" 兩個 tab 分開編輯; 工具明細的 "編輯工具說明" 會開啟相同視窗並搜尋該工具. 保留搜尋, 逐列儲存, 儲存本頁修改與逐列還原預設; 分頁或切換 tab 會保留尚未儲存的草稿, 重新載入前需先儲存

介面設定可調整完整的狀態, 分類, 欄位, 提示與標題. 數字, 單獨單位, "個工具" 等拼接片段不列入; 新增完整標籤會自動加入. 套用後即時更新, 包含圖表控制項; 介面最多保存 500 項自訂文字

"全部還原預設" 會先顯示確認視窗, 明確列出所有自訂介面文字, 工具說明與未儲存草稿都會清除. 取消, Esc 或點外側不套用; 確認完成後顯示還原結果. Tab 順序的全部還原也需確認

每個說明最多 400 字元, 工具用途可保存 64 個自訂說明; 未收錄的新工具保留名稱並可立即補充說明. 文字以純文字顯示

設定與說明保存在目前網站的 localStorage, 依瀏覽器與 origin 隔離; 後端只維持目前程序的設定, 畫面重新連線後套用瀏覽器保存值. 程式版本更新後會篩除已移除或無效的設定欄位

## Skill 文件與程式狀態

點 Skill 名稱可查看該目錄與子目錄的檔案清單, 包含文件, Python 腳本與其他檔案. 清單可排序與分頁, 顯示相對位置, 格式, 大小與更新時間; Python 與其他檔案只顯示檔案資訊, 不讀取原始碼

若有 README.md 優先顯示. 點 Markdown / TXT / RST / AsciiDoc 文件可讀取目前內容, 查看檔案位置與讀取片段的 SHA-256; 文件讀取會遮蔽 credentials. 每次最多列出 200 個檔案, 掃描 1000 個項目與 4 層子目錄, 達上限時顯示提示; 找不到檔案會顯示明確狀態

程式狀態 tab 顯示啟動時間, uptime, Python / 平台 / 版本 / PID, 本輪整理 / CPU 時間, Codex session 讀取量, HTTP 計數, snapshot / 傳輸大小與狀態事件. 效能趨勢可調時間範圍與每格間隔; 耗時 / CPU 以區間平均顯示, 讀取量加總. 最多保留 360 個樣本與 200 個事件, 重新啟動後重新累積; Jev 資料庫大小是主 SQLite 檔大小, 不含 WAL / SHM. 詳細上限見 [程式架構](architecture.md)

## 網路參考

網路 tab 將工具與參考資料合併為同一張表格, 每列顯示工具, 結果, 時間與參考網址數量; 點整列或數量開啟明細才列出網址, 可在新分頁開啟. 對話明細也保留相關 Web 操作. 網址保留 scheme / host / path, 移除 query 與 fragment, 排除含帳密及內部 IP 的 URL; 需要 query 才能定位的頁面可能需要自行補回公開參數

多個工具共用的 exec 回傳無法確認各網址所屬工具時, 只保留呼叫參數中已知的開啟網址

## 檔案操作

檔案表格上方可搜尋位置, 篩選操作, 專案, 工具與工具呼叫 / exec 辨識. 各 tab 先顯示摘要與圖表, filter 放在對應表格上方; 一般表格依欄位自動提供搜尋與篩選, popup 表格保留排序 / 分頁與欄位設定. 從 apply_patch header, Get-Content / cat / head / tail / sed 等明確讀取路徑, Set-Content / Add-Content / Out-File 的 literal 寫入位置, 以及工具名稱與 path / file_path 等參數辨識讀寫; 未知 MCP 的 read / write 類工具也可加入紀錄

紀錄保存位置與所屬工具 metadata, 不讀取目標檔案內文. 變數或 glob 路徑不展開; 相對路徑若有 workdir 會一起顯示. 點整列可查看 Call ID, 時間, 工具用途與對話; exec 內的個別耗時為未知, popup 可看整次 exec 耗時

總覽保留各 tab 摘要入口, 點 MCP 分類摘要可直接套用該分類

## 錯誤紀錄與資料來源

右上錯誤按鈕顯示最近 24 小時已載入的錯誤數, 點擊切到錯誤紀錄並選擇「錯誤」等級. 表格可切換錯誤 / 警告, 依類型, 對話, 專案, 來源與工具篩選; 一筆是來源的診斷事件, 同一個送出失敗可能由不同模組各留一筆

明細顯示時間, 等級, 代碼, 來源模組與可取得的 HTTP / exit code, 可用按鈕開啟相關對話或 MCP 操作. 對話明細有錯誤紀錄子 tab; popup 上方返回按鈕保留上一個明細的子 tab 與捲動位置. 每個 popup 可按外側, Esc 或關閉圖示關閉

對話與工具錯誤 switch 控制診斷讀取與 session / tool error 解析; 觀察程式自身的錯誤仍保留. 原始 errorMessage / stack / command / prompt 不保存, 可用 metadata 詳細見 [錯誤觀察](error-observation.md)

對話資訊列出資料與狀態來源. 沒有開始 / 完成事件的 session 會在每輪讀取額度內向前回查, 回查中會明示狀態來源; 找到後補回執行中 / 已完成與起訖. 雲端 ChatGPT 對話如果只有本機目錄, 來源未提供的 Model / Reasoning / token / 工具欄位維持未知

## 設定檔

設定 → 設定檔可匯出完整偏好或選擇 / 貼上 JSON 匯入. 匯入先驗證並顯示確認視窗, 列出圖表 / 表格數量與 Jev 紀錄狀態; 取消不套用, 確認後套用並重新載入. 匯出時同時顯示可複製的 JSON 內容

設定涵蓋外觀, 顯示數量, 更新 / 追蹤, 觀察 switch, MCP 分類 / 開關, 工具用途, 介面文案, Tab 順序, 各圖表與表格, 篩選, 頁碼及欄位順序 / 顯示. 換電腦後會依當前來源與可用欄位套用; 格式, 上限與保存位置見 [設定檔格式](settings-format.md)
