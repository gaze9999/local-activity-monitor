# 使用說明

| 主頁 | 子頁與用途 |
| --- | --- |
| 總覽 | 選擇及排序圖表、帳戶資料與活動摘要 |
| 用量與額度 | Token 分析、方案與帳戶額度快照 |
| 對話 | 對話列表、Context、排程、子代理程式與 My dots |
| 專案 | 專案列表、Git 操作、工作樹與驗證活動 |

| 監測程式 | 收集進度、效能、硬體與資料保存 |

左上顯示 LAM 與 WBUI 版本, 右上資訊區維持兩行. 第一行顯示連線狀態與額度, 額度依「重設時間 · 期間 剩餘比例」排列, 7 天在前, 5 小時接在右側. 第二行顯示更新時間、整理頻率、資料來源、活動紀錄保存天數與執行時間. 窄螢幕的額度區可橫向捲動查看完整資訊. 頁首時間選單統一控制來源紀錄範圍, 預設最近 24 小時, 可選 1 小時、7 天或全部

「資料來源」顯示最近檢查正常的來源數 / 啟用來源數, 與來源 Log 使用同一份讀取器清單. 來源 Log 也列出停用來源, 所以完整列數可能多於頁首的啟用來源數. 「活動紀錄」表示 LAM 保存摘要的天數, 0 表示不自動刪除, 回補完成後隱藏進度

來源的「最近檢查時間」取自實際讀取、查詢或保存檢查. 沿用快取或只重新顯示頁面時保留原時間, 讀取與保存分別記錄

主頁摘要預設四項, 子頁摘要預設隱藏. 頁面齒輪可選顯示項目、數量及順序. 最新對話狀態、累計 Token、額度與工作樹保留來源快照, 操作列表及統計使用全域時間範圍

點擊對話或操作列開啟明細, 鍵盤聚焦後可按 Enter / Space. 關聯對話與工具提供導覽按鈕, 可返回上一個明細, 使用 Esc、外側或關閉按鈕離開. 主頁及子頁切換保留頁面捲動位置, 明細 Tab 切換回到內容頂端

明細的第一個分頁為「概要」, 執行內容、文件、相關對話及讀取紀錄依內容分頁. 右上角最多保留一個關聯導覽入口, 複製追蹤資料、重新讀取及其他操作留在所屬分頁

背景更新保留已開啟的明細、展開狀態、捲動位置與編輯草稿. 空資料顯示說明, 來源缺值顯示 `--`, 已確認的零與 false 保留原值

## 表格與排序

篩選預設收合, 展開後可依目前頁面的對話、專案、模型、狀態及工具篩選. 收合時保留條件並顯示已套用數量

表格預設每頁 10 筆, 齒輪可設定筆數、排序、欄位及欄位順序. 完整篩選結果先排序再分頁, 缺值置後. 頁碼按 Enter 或離開欄位套用, 更新期間保留輸入草稿

分頁列置中, 首頁、上一頁、下一頁與末頁使用 SVG 按鈕. 下一頁向左滑入, 上一頁向右滑入, 跳頁依目標頁碼判定方向. 快速連點以最新頁面為準, 減少動畫設定會直接呈現結果. 欄位超出容器時, 橫向捲動留在表格內

表格可從標題收合, 收合後顯示篩選筆數與最近時間. 桌面橫向捲動限於表格容器, 760 px 以下改為帶欄位名稱的資料卡. 全部對話以每批 50 列載入

數值熱度預設關閉, 可設定全域預設或個別表格覆寫. 顏色依目前頁面逐欄比較已知數值, 深色表示較大值

右上「拖曳排序」預設關閉. 開啟後可拖曳主 / 子 Tab、表頭及卡片標題, 各區獨立保存順序. Tab / 表頭使用 Alt + 左右方向鍵, 卡片及垂直項目使用方向鍵 / Home / End. Modal 內的排序保持固定

## 圖表與卡片

[卡片庫](card-library.md)列出各來源可用的趨勢、比較、排行、分布及統計卡. 各頁齒輪選擇要顯示的卡片, 總覽副本保留獨立參數

卡片使用 WBUI 共用布局, 總覽最多四欄, 其他圖表及一般資訊卡依數量使用一至三欄, 窄螢幕改單欄. compact 模式縮短不同高度卡片之間的空隙

圖表齒輪設定圖形、範圍、起訖、間隔、顯示數量、線數與上限. 趨勢支援折線、面積及長條, 分布支援橫條、直條、堆疊直條、圓餅與環圈, 可用形式依卡片列出. 多線圖預設 3 條, 可選 5 / 10 條

上限 `0` 使用自動刻度. 自訂上限低於峰值時圖形截短, tooltip 保留實際值. 過長標籤顯示省略號與完整提示, 單位與刻度保留間距. 趨勢圖提供鍵盤左右 / Home / End 讀值, 最多 240 個樣本區間

統計卡顯示平均值、P99、總數與樣本數. P99 使用線性內插計算第 99 百分位數. 耗時使用有效樣本, 活動趨勢包含零活動樣本. 分布與額度依自身資料形式呈現

## 用量與帳戶

Token 使用每個 thread 的最新累計值. Cached input 包含於 Input, Reasoning output 包含於 Output. 模型圖表及表格可開啟所屬對話明細, 快取命中率以 Cached input / Input 計算, 輸入缺值或為零時顯示 `--`

額度列出方案、視窗、剩餘比例、已使用比例、重設時間與 credits. 進度條表示剩餘量, 重設時間到達後等待來源回報

主設定的「官方帳戶查詢」預設關閉, 啟用後透過已登入的 Codex CLI 查詢. 成功與失敗結果至少快取 60 秒, 每次最多等待 10 秒, 回傳上限 1 MiB. 方案名稱使用來源值, 帳戶 Token 與已載入對話 Token 分別呈現

## 對話、專案與工具

Session 掃描全部可取得的來源, 分批讀取與回補, 以容量上限管理記憶體工作集合. 狀態依 `task_started` / `task_complete`, 缺少事件時反向回補. 有效 checkpoint 在重啟後沿用

對話明細提供獨立的 Context 分頁, 切入後才讀取目前對話的近期訊息與公開思考摘要, 顯示父 / 子代理角色與父對話入口. 分頁切換保留已讀取內容, 「重新讀取」取得最新來源, 代理訊息另列傳送與回傳明細

代理訊息沒有資料時顯示目前範圍的空紀錄提示, 來源仍在回補時顯示整理中. 分頁標題不再重複列於內容區

Skills 保存最近 500 筆檔案讀取 metadata, 依 Thread / Call ID / Skill 去重. 點擊開啟明細與已觀察目錄的檔案樹, 文件需有可讀取的來源路徑

專案列出已載入的對話關聯. 點擊 Git 與驗證操作查看指令及工具回傳, 工作樹明細列出位置、分支、HEAD、狀態與關聯對話

MCP 來源從設定與已載入工具紀錄發現, 包含全部來源與個別來源子頁. 用途優先使用來源 description 或設定 README, 來源卡顯示簡短說明, 完整內容在 tooltip 與明細中提供

MCP 指標依來源提供的型別與單位分類, 包含用量、credits、耗時、節省、文件、瀏覽器及驗證. Exec 內的工具按程式碼呼叫位置計數, 多工具共用回傳保留外層來源

Plugins 列出設定啟用狀態、快取、供應商、版本及 Skills / MCP 數量. 排程列出本機設定與桌面快取中的遠端排程活動. My dots 列出近期活動電腦、活動與產出紀錄. 近期活動電腦的目前連線狀態尚未取得, 即時連線與完整遠端排程定義見[功能清單](features.md)

## SQL、網路、檔案與 Log

SQL 由工具參數、sqlite3 命令、literal Python SQLite 呼叫及診斷紀錄辨識. 點擊查看已記錄的 SQL, 個別 SQL 耗時、外層工具耗時及列數分列. 明細遮蔽預設開啟

網路列出工具操作、參考網址與網站統計, 同一次操作的重複網址合併. 網址保留頁面路徑並移除 query / fragment

檔案頁提供讀取、異動、已觀察的讀寫量與目前大小排行. 進入頁面後自動檢查大小, 頁面顯示期間每分鐘更新, 可手動重新檢查. 每次最多取得前 100 個不同的已觀察位置, 超出部分尚無分批續查

一般檔案明細列出位置、範圍、讀寫量與檔案異動時間. 有對應的 Thread / Call ID 時, 可切入「執行內容」讀取工具送出與回傳資料, 切換分頁保留已讀取內容, 關閉或離開明細時取消尚未完成的要求. 一般檔案內文列於[待實作項目](features.md), 技能與 MCP 文件已有各自的按需內容入口. 送出文字大小使用 UTF-8 bytes

Log 等級保留 error / warn / info / debug / trace 等來源值. 錯誤明細顯示分類、時間、模組、代碼、Request / Trace / Call ID 及相關事件, 原文按需取得

工具、MCP、Git、SQL 及 Log 內容先遮蔽再分頁, 每頁最多 32,768 字元, 接近捲動區底部時自動載入. JSON、JSONL、literal 物件及 YAML 子集可結構化呈現, 提供原文切換. TOML、XML、CSV / TSV 保留原文, 結構解析列於 [待實作項目](features.md). Markdown 支援標題、清單、表格、連結與程式碼, HTML 保留文字形式

## 設定與更新

右上齒輪提供外觀、顯示、更新與追蹤、介面與說明、監測項目、MCP 來源、來源紀錄及設定檔. 字級預設 14 px, 範圍 12 - 18 px, 字型選單使用本機可用字型, 保留已保存的自訂值, 強調色可自訂

欄位 tooltip 說明資料意義. 工具用途與說明可直接編輯, 編輯框隨文字調整, 變更後顯示儲存 / 取消. MCP 資料檔儲存前檢查格式與版本, 已遮蔽、截短或程式碼檔使用唯讀檢視

更新預設 10 秒, 可設定 1 - 3600 秒. Codex 閒置預設五分鐘暫停完整整理, 有新活動時恢復, 設為 `0` 關閉閒置暫停. 本機 SSE 通知完成的資料更新, 斷線時使用定時查詢. 瀏覽器隱藏時關閉串流, 回到前景重新查詢與訂閱

SQL、網路及 MCP 活動摘要預設保存 90 天, 可設定 0 - 3650 天, 0 表示不自動刪除. SQL 最多 500 筆, 網路及 MCP 各 1000 筆, 合計最多 1 MiB. 縮短保存天數移除過期摘要

設定 JSON 可匯出、選檔或貼上匯入, 預覽後確認套用. 還原預設先確認, 活動紀錄保留. 欄位及上限見 [設定檔格式](settings-format.md)

## 監測資訊

監測頁顯示整理階段、讀取與回補量、CPU 時間、記憶體、GPU、runtime、資料上限與頁面效能. 來源詳細說明在頁尾預設收合, 展開顯示實際位置、健康狀態、選取欄位、保留量及讀取上限

瀏覽器指標及收集流程見 [效能與資料上限](performance-report.md), 各來源的資料格式見 [資料盤點](data-inventory.md)

右上角保留兩行資訊, 顯示連線、資料整理頻率、資料來源的最近檢查成功數、活動紀錄保存天數. 每個額度視窗旁顯示其重設時間, 回補完成後隱藏進度. 來源數量與來源 Log 的檢查列共用資料, 分母計算已啟用來源, 包含目錄、記錄檔與資料庫的各個讀取器

對話列表預設顯示對話名稱、狀態、模型、總 Token、平均 Token / 秒與最近活動時間. 平均速率使用最新累計 Token 除以已記錄工作時間, 缺少時間時顯示缺值. 其他欄位可由表格設定開啟, 有效自訂欄序與顯示偏好保留

點選整列開啟主要明細, 列內按鈕或連結提供相關對話與不同操作. 專案明細的對話階層及技能檔案樹預設收合, 可用方向鍵展開與移動. Context 位於對話列表後, 主頁及子頁順序可由拖曳排序調整

直向螢幕依可視寬度安排卡片, 768 - 1,200 px 的直向畫面採兩欄摘要與卡片, 更窄的畫面採單欄內容. 摘要及子頁籤各自成區, 寬表格在表格區域內捲動, 明細視窗配合可視高度限制內容區

檔案大小在進入檔案頁後自動檢查, 頁面持續顯示時每分鐘更新, 重新檢查按鈕可立即取得新值. 每次最多讀取 100 個已觀察檔案的 metadata, 清單標示檢查時間與已取得 / 總數
