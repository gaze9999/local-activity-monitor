# 使用說明

## 頁面與明細

| 主頁 | 子頁與用途 |
| --- | --- |
| 總覽 | 圖表與活動摘要入口, 可個別選擇顯示項目與排序 |
| 對話 | 對話列表, 用量與額度, My dots |
| 錯誤與 Log | 錯誤紀錄, 來源 Log 與讀取狀態 |
| 工具 | 工具排行, 用途與程式碼中辨識到的工具 |
| MCP | 全部來源與動態來源子頁, 包含 Jev 與各來源提供的指標 |
| 網路 | 網路操作與參考網址數量 |
| 檔案 | 檔案讀寫, 修改位置與所屬對話 |
| SQL | SQL / SQLite 操作, 診斷與所屬對話 |
| Skills | Skills 讀取排行, 關聯對話與文件明細 |
| 專案活動 | Git 操作, test / build / lint 與型別檢查 |
| 監測程式 | 資料更新耗時, CPU 時間, 讀取量, 保存狀況與執行事件 |

左上顯示程式名稱與版本, 右上顯示更新時間, 更新頻率, 程式啟動時間與執行時間. 執行時間每秒更新. 主頁與子頁的 Tab 不折行, 空間不足時橫向捲動. 各主頁最下方列出資料來源, 讀取方式與範圍

點對話列開啟明細, 聚焦後也可按 Enter / Space. 對話名稱與該列使用同一入口, 不放重複按鈕. 連到不同明細的關聯對話與工具使用按鈕. Popup 支援返回上一個明細, 保留子頁與捲動位置. 可用 Esc, 外側或關閉按鈕關閉

狀態標籤在列表與明細一致: 執行中為藍色, 已完成為綠色, 錯誤 / 失敗 / 逾時為紅色, 等待中 / 排隊中為黃色, 回補中為紫色. 其他狀態維持中性色. 文字標籤保留, 指向可查看最近確認時間與回補狀況

缺少數值或來源未提供的欄位顯示 `--`, 已確認為零的計數顯示 `0`, 已確認沒有錯誤顯示「無」. Model 與推理等級依最新設定事件合併, 缺少時使用本機 catalog 可提供的值. 明細列出資料與狀態來源

## 對話追蹤與狀態

設定的更新與追蹤可調近期 session 數量 (1 - 5000, 預設 20), 或追蹤全部, 上限 5000. 每輪 session 讀取共用 8 MiB 預算, 初次讀取頭行與最多 1 MiB 尾端, 之後增量讀取

狀態取自 `task_started` / `task_complete`, 缺少時優先反向回補工作事件. 最近確認的狀態與讀取位置採循環保存, 程序重啟後可沿用. 程式停用期間若有未涵蓋的紀錄, 保留最近狀態並繼續回補, 明細與 tooltip 顯示來源與確認時間. 不以對話建立時間推估工作耗時

Skills 保存最近 500 筆選定讀取 metadata, 依 Thread ID, Call ID 與 Skill 去重. 重新整理與重新啟動保留此範圍的計數. Skills 讀取不等同已使用. 重啟後尚未重新觀察文件路徑的紀錄保留讀取次數, 不提供文件讀取入口

純 ChatGPT 雲端對話由本機 catalog 提供名稱, 時間與分類. 若 catalog 有 Model, 推理等級與 async status 就讀取. 沒有 session 或來源未提供的 Token / 工具次數維持 `--`

## 表格與排序

各頁與表格的篩選區預設收合, 可展開 / 收合, 收合時保留條件並列出已套用數量, 狀態保存在目前瀏覽器與設定檔.

表格齒輪可設定每頁筆數, 排序欄位, 方向, 顯示欄位與欄位順序. 先排序完整篩選結果再分頁, 缺值置後. 頁碼可按 Enter 或離開欄位套用, 自動更新保留正在輸入的頁碼

桌面多欄表格在表格範圍內橫向捲動, 表頭保留在可讀位置. 760 px 以下改成帶欄位名稱的資料卡. 選擇全部對話時每批建立 50 列, 捲動或按載入更多後再增加

數值熱度預設關閉, 可在表格設定啟用. 以目前頁面顯示的資料逐欄比較, 顏色越深代表數值越大. 僅套用已知數值, 不將 ID, 日期或缺值當成數值

右上「拖曳排序」預設關閉. 開啟後可直接拖曳主 / 子 Tab, 表頭, 欄位選項, 圖表標題, 活動摘要與其他頁面的卡片標題. 不顯示握把圖示, 各區域獨立排序, 頂部主要數值卡不參與. 拖曳時有浮動預覽與插入位置提示, 靠近邊緣會捲動

Tab / 表頭可用 Alt + 左右方向鍵調整. 垂直項目與卡片標題可用方向鍵 / Home / End. Modal 有獨立的拖曳開關, 每次開啟預設關閉, 與主頁分開. 關閉拖曳開關時排序快捷鍵也停用. 順序使用原始識別保存, 自訂文案不改變對應. 新項目接在保存順序尾端

## 圖表與統計

各圖表齒輪調整時間範圍, 起訖, 間隔, 顯示項目與數值上限. 趨勢提供長條 / 折線. 分布提供橫條, 直條, 堆疊直條, 圓餅與環圈. 有完整分類時顯示分段, 缺少時保留未分類總量

總覽的圖表各自固定類型, 分開顯示. 總覽 Tab 設定可選顯示與排序, 與下方活動摘要分開. 可加入 Git, Skills, 驗證, 剩餘額度, My dots, 網路, 錯誤, 資料更新耗時與讀取量等圖表. 其他頁面保留圖表類型切換

直條與趨勢圖包含刻度, 單位與格線, 0 上限代表自動. 自訂上限低於峰值時圖形截短, tooltip 保留實際值. 分布圖的總量與圖例放在圖形外, 避免長數值擠壓環圈中心. 直條標籤依實際字體與可用寬度判斷, 需要傾斜時整組一致傾斜. 太長保留省略號與完整 tooltip

耗時與時間趨勢提供平均值, P99, Low 1% (P1) 與含樣本數的統計範圍. 分類排行, Token 分布與額度快照不顯示這些統計. P99 / P1 使用線性內插, 分別表示第 99 / 1 百分位數. 耗時與 CPU 使用有效樣本, 活動趨勢包含零活動時間格

圖表資料取自目前載入紀錄. 模型 / 執行位置 / 活動來源依對話最近活動時間篩選, 工具依呼叫時間篩選. 趨勢最多 240 格, 長區間自動放大間隔. 滑鼠或鍵盤可查看數值, 趨勢圖支援左右 / Home / End

## 用量, MCP 與 My dots

用量頁列出本機已取得的方案, 額度視窗, 剩餘比例, 已使用比例, 重設時間與 credits. 進度條顯示剩餘量, 到達重設時間後等待來源更新. 不隨時間推估額度. Token 分析採每個 thread 最新累計值, 不重複加總歷次快照, Cached input 與 Reasoning output 不再加進 Total

MCP 來源由設定與載入的工具紀錄發現, 各來源有獨立子頁. 只有全部來源子頁列出完整來源卡片, 選單一來源時只列該來源操作. 用途優先取來源 description 或已設定 README, 可在設定修改. 有用途資訊時顯示, 缺少時省略用途區塊. 分類標籤依來源與工具名稱補充文件查詢, 搜尋, 資料庫, 瀏覽器等用途

來源提供的指標依載入欄位分成用量, Credits 與費用, 耗時, 節省與壓縮, 瀏覽器與頁面, 驗證或執行結果. 列出選定數值與 boolean metadata, 包含用量, credits, 重試, 文件數與耗時. 一般指標保留最新值與時間, 耗時提供樣本數, 平均, P99 與 P1. 不將多個工具共用的 exec 回傳分配成個別結果. 程式碼辨識是呼叫位置, 不推估實際執行次數

MCP 標籤由用途, 工具名稱與回傳欄位推導, 可在設定搜尋來源並編輯最多 4 個標籤. 未知來源會自動加入觀察. 來源紀錄頁顯示實際紀錄狀態, 開關由來源管理, dashboard 不自動啟用紀錄.

連線狀態使用本機呼叫, 回傳與傳輸錯誤, 列出最近回應時間與尚無回傳的呼叫數. 這項觀察不呼叫 MCP 或消耗額度.

Jev 位於 MCP 子頁, 透過共用來源區塊顯示本機用量, HTTP 嘗試, 大小, 操作明細與活動紀錄. 未知的操作 / 狀態與符合單位規則的新增指標也會顯示. 有本機來源紀錄時, 頁首可選擇來源紀錄範圍, 此範圍適用本機紀錄區塊. 指定呼叫明細才讀取可獨立辨識的送出 / 回傳, 遮蔽 credentials, 不另存內容. My dots 顯示已取得的產出類型, 時間與關聯對話. 來源提供名稱時套用, 缺少時使用 My dots

## 設定與說明

右上齒輪使用側邊分類, 包含外觀, 顯示, 更新與追蹤, 介面與說明, 監測項目, MCP 來源, 來源紀錄與設定檔. 小螢幕改成橫向導覽. 提供繁體中文, English 與日本語, 字體 12 - 18 px, 主題與強調色. 更新頻率為 1 - 3600 秒, 數量 / 字體等設定四捨五入為整數

介面與說明分工具說明, 介面設定與指標說明子頁, 有搜尋與分類篩選. 保留未儲存草稿, 逐列或整頁儲存. 有自訂內容才顯示還原預設, 文字以純文字處理, 每項最多 400 字元. 成功 / 失敗使用短暫浮動通知, 不改變頁面配置

Tooltip 共用樣式, 靠近右邊界時向左調整. 開啟 modal 後隱藏原提示, 關閉後不因恢復焦點再次彈出. 欄位, 統計, 圖表與設定皆可查看必要解釋. Esc 關閉

設定檔可匯出或選擇 / 貼上 JSON 匯入, 預覽確認後套用. 全部設定還原預設會先確認, 還原外觀, 語言, 顯示, 排序, 圖表, 表格, 文字與觀察設定. 已有活動紀錄保留. 保存欄位與上限見 [設定檔格式](settings-format.md)

## 錯誤與來源 Log

右上錯誤按鈕顯示最近 24 小時已載入錯誤數, 點擊直接篩選錯誤. 錯誤與來源 Log 使用子頁, 可依來源, 等級, 對話, 專案與工具篩選. Log 等級沿用 error / warn / info / debug / trace

錯誤明細提供原因分類, 時間, 模組, 錯誤類型 / 代碼, HTTP / exit code, Request / Trace / Call ID, 來源檔名 / 紀錄 ID, 可取得的原因與相關事件. 有關聯時可開啟對話或工具. 同一操作可能在不同來源各有紀錄

啟動時分批回讀既有 App / Core / session Log, 補上最近 24 小時可取得的錯誤. 選定錯誤摘要採循環保存, 網頁重整與程序重啟後保留. 程式自身只寫啟動, 設定, 失敗 / 恢復等少量事件. 詳細讀取範圍與資料邊界見 [錯誤觀察](error-observation.md)

## SQL, 網路, 檔案與 Skills

SQL 從工具參數, sqlite3 命令, literal Python SQLite 呼叫與 SQL 診斷辨識, 不執行來源程式碼. 分開列出 SQL 診斷的個別耗時與整次工具耗時. 沒有可辨識紀錄時操作計數為 0. 來源沒記錄的 Codex 內部 SQLite 讀寫無法從此計數推知

網路表格只顯示參考網址數量, 點明細才列網址. 移除 query / fragment, 排除 URL credentials 與內部 IP. 檔案從 literal 讀寫位置與 patch header 取得 metadata, 不讀取檔案內文, 不展開變數或 glob

Skill 文件入口依目前已觀察路徑列檔案 metadata. Markdown / TXT / RST / AsciiDoc 可讀取並遮蔽 credentials, Python 等非文件只列資訊. 每次最多列 200 個檔案, 掃描 1000 個項目與 4 層目錄, 每份文件最多讀取 256 KiB

監測程式的耗時與 CPU 圖表提供平均, P99 與 P1. 最多 360 個效能樣本與 200 個執行事件. 瀏覽器隱藏時停止畫面輪詢, 後端仍收集. 來源位置, 保存容量與涵蓋範圍可在頁面底部查看
