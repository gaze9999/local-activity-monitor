# 維護與驗收

依實際修改選擇下列項目, 記錄版本 / diff, fixture, 執行方式與結果. 完成前回顧當次對話的追加需求, 在最後修改後統一檢查受影響主頁, 子頁, modal 的排版, 文案, 資料與效能再執行已授權的 commit / push / release, 不用靜態檢查代替實際介面或平台驗證

## 資料與觀察來源

- 沿 source -> collector -> API -> UI 追查新增與變更欄位, 核對來源健康狀態, 時間, 單位, 型別, 統計範圍, 去重及截斷. 來源未提供用 --, 已確認沒有事件 / 錯誤用無, 已確認數量為零用 0. 不用空白隱藏缺值, 不用未知掩蓋讀取失敗
- 對話檢查最新狀態, Model / Reasoning, 起訖時間, 分批歷史回補與 checkpoint. Skills 依 Thread / Call ID / Skill 去重, 更新與重啟不得重複加總或無故歸零. Token 不加總累計快照, 快取 Token 不再次加入總量
- MCP 檢查新來源自動出現, 自訂分類 / tag / 用途, 直接呼叫與 exec 辨識, 狀態 / 錯誤, 用量 / credits / 節省 / 瀏覽器 / 文件 / 驗證等來源提供的欄位. 未知來源沿用通用流程, 不依工具名稱假造指標或結果. 專有資料可加投影, 不另建一套設定或硬編碼 UI
- 紀錄開關由來源決定, 缺少來源功能時不提供假的開關. 啟動, 匯入及還原介面設定不自動改寫來源. 連線狀態只讀本機紀錄, 不用 paid API 或主動呼叫確認. 沒有觀測證據時省略連線 tag
- SQL 只辨識 literal 工具參數 / 程式碼及 SQL 診斷, 不執行來源. 操作數, 個別 SQL 耗時, 外層工具耗時, rows_affected / rows_returned 要分開. 內容明細綁定已觀察紀錄, 限量讀取, 遮蔽可辨識憑證, 不加入 snapshot 或保存 DB
- 錯誤與 Log 明細核對原因, 等級, code, Thread / Call / Request / Trace ID, 檔名 / 紀錄 ID, 關聯操作與來源狀態. 保留來源有提供的追查欄位, 不用一般內文字詞猜測失敗或回傳成功

## 介面與多國語言

- 同步 zh-TW, en, ja 的介面 / tooltip / 空狀態 / 按鈕與通知, 檢查 key 完整及變數 / 單位沒有被翻譯破壞. 實際切換語系, 主頁, 子頁, 設定與 modal 均需可操作. 台灣用語, 精簡文案與半形標點沿用上層指示, 不加入無關的排除式解釋
- 桌面及窄螢幕檢查長名稱, 大數值, 空資料與更新後的版面. 容器需可縮小, 多欄位置不因數值長度交換, 不同高度卡片可接續使用空間並維持欄位順序. 標籤 / 單位不出界, 卡片與頁面不產生無意義空區
- MCP 來源與對話子 Tab 自動換行, 不使用水平捲軸, MCP 來源固定展開並只顯示來源標題. 其他 Tab 依共用導覽處理空間. 保留選取 / 鍵盤操作 / ARIA, 滑鼠 focus 不加多餘外框. 卡片與 Tab 拖曳直接操作元件, 預設關閉, 只在主頁提供開關, modal 內停用, 不能跨區移動, 順序需保存. 拖曳說明只在所屬區域的排序開關啟用後顯示
- 每個主分頁上方預設四項重要摘要, 數量與項目可自訂, 副標優先顯示次要觀測值, 缺少資料時提供解說. 子頁不顯示摘要卡或摘要設定, 細節依用途置於子頁與明細. 總覽圖表維持四欄, 其餘圖表及一般資訊卡依數量使用一欄, 兩欄或三欄, 相鄰圖表接續填入較短欄位. MCP 來源與活動摘要等小卡沿用較密集的排列, 窄螢幕改單欄. 圖表在表格之前, 所有排行預設前 5 項, 數量選擇放在卡片齒輪
- 圖表核對刻度, 單位, 圖例, tooltip, 超長標籤, 大數值, 狹窄卡片, 隱藏頁面再次顯示與不同語系. 標籤角度依可用空間決定, 同一圖表統一角度, 縮略要有完整 tooltip. 環圈總值可放圖外, 圓餅資訊另列. 平均 / P99 / P1 只用於有意義的分布, 分類與額度卡不加入耗時統計
- 表格預設每頁 10 筆與必要欄位, 篩選預設收合, 分頁 / 排序 / 搜尋 / 模型與狀態等篩選依實際資料有效. 介面字級預設 14 px, 放大後仍需檢查卡片 / modal / 控制項排版. 按鈕 / tag 有一致間距, Tag 以顏色區分狀態與分類且保留文字, Log 等級維持英文. 表頭隨內容捲動, 不使用浮動表頭. 桌面橫捲只限表格容器, 窄螢幕資料卡保留欄位資訊
- 設定修改核對保存, 匯入預覽 / 取消, 全部還原預設, 整數正規化, 有變更才顯示還原, modal 內不提供拖曳排序. 通知不阻擋操作或改變排版. 關閉 modal 後原 tooltip 不得因 focus 返回而重新冒出
- 更新時間, 開啟時間與運行時間集中於右上角 2x2 狀態區, 更新與更新頻率同行, 操作按鈕另列靠右. 版本與標題分開, 來源說明只在使用資料的頁面顯示. 內部連結切換分頁後定位頁首或相關區塊, 不沿用前一頁的捲動位置
- 頁尾的詳細來源說明預設收合, 位置, 上限, 欄位與數量來自當次讀取結果. 未讀取或不可用需保留實際狀態, 不用固定檔名樣板或補零表示. 展開及切換子頁後應更新內容, 不追加掃描或讀取完整 payload

## 共用介面的設計依據

- 設定靠近相關內容, 基本選項先顯示, 詳細選項集中在齒輪. 依 [NN/g 的自訂介面指引](https://www.nngroup.com/articles/customization/) 與 [漸進式資訊展開](https://www.nngroup.com/articles/progressive-disclosure/), 保留可直接使用的預設, 不要求先自訂才能看到資料
- 來源的詳細位置與讀取結果使用可折疊區塊, 主要指標維持可見. 依 [GOV.UK Details](https://design-system.service.gov.uk/components/details/) 的用途區分主要內容與補充資訊, 摘要需清楚說明展開後可看到什麼
- 表格維持一致的工具列, 篩選與分頁, 桌面橫捲只在表格內. 參考 [Carbon Data table](https://www.carbondesignsystem.com/building-blocks/core/components/data-table/guidelines). 5 項排行, 10 筆表格與 14 px 字級是本專案的預設選擇

## 效能與交付

- 保持增量讀取, 分批回補, 白名單投影及既有檔案 / 行 / bytes / rows / 事件保存上限. 一般 refresh 不讀完整 payload, Skill 文件或任意檔案, 詳細內容按需讀取. 不為來源連線狀態加入探測或額度消耗
- 同一 fixture 比較冷啟動與後續更新, 檢查讀取量, CPU / 耗時, HTTP / 壓縮大小及 DOM 更新. 切換頁面, 隱藏瀏覽器, 篩選, modal 與大型資料集不得觸發無必要重掃或累計重算
- focused unittest 驗證資料及 endpoint 邊界, 實際服務頁面驗證 JS / CSP, console / network, 設定, 互動與排版. 新增來源 / 多種格式需要 fixture, 不從範例測試推論正式 provider 已驗證
- release 檢查版本一致, wheel / sdist / 原生套件包含完整 web assets, 語系, runtime 與授權文件, 多平台啟動及 loopback / 檔案邊界, CI 狀態與產物 checksum. 未驗證平台或失敗工作要明確列出

## 共用布局與按需明細

- 每個主頁維持單行用途說明, 右上來源範圍選單與齒輪使用相同順序, 子頁與 modal Tab 以 tooltip 說明用途, 切換後回到內容頂端. 不讓不同頁面使用互相矛盾的工具列排法
- 核對全域與主 / 子頁來源範圍覆寫, 預設 24 小時, 列表與操作統計一起篩選. 最新狀態, Token 與額度保持快照語意, 缺少時間只在全部範圍顯示
- Skills 各列均能開啟 metadata 明細, 文件內容依可取得的路徑按需讀取. 專案 / 子代理程式關聯只涵蓋已載入資料, 不把子代理狀態當成父對話狀態
- Global / Project AGENTS.md, 專案資料夾與已觀察 Git 操作內容只按需取得, 不存入 snapshot / checkpoint. 結構化 JSON 或 literal 資料只解析及顯示, 不執行程式碼, 詳細內容預設收合
- 排行沿用圖表卡片及齒輪, 詳細統計表另置於獨立區塊. 核對網址與資料夾排行點擊, 模型用量明細, 技能檔案進入與返回, 已展開 JSON 及內容捲動位置在自動更新後保留
- 檢查 SQL, 網路與 MCP 摘要在空來源更新, 重啟與未知來源出現後的保存, 到期, 上限與去重. 同一 call 的較少欄位更新不能清空已取得的回傳與數值
- 檔案大小僅按需檢查已取得路徑, 核對 100 個位置上限與不接受任意檔案的 API. 讀寫量, 送出文字大小及目前檔案容量分別驗證來源與單位
- 所有表格全寬, 預設展開且可收合. 標題與表格相同語意時合併, 副標題置於展開內容, 無篩選時移除工具列留白. 核對重新整理後展開選擇, 欄位順序, Tag 與正在編輯內容保留. 數值熱度支援全域預設與表格覆寫
- MCP 來源卡說明最多三行, 完整內容由 tooltip 與明細提供. 本地文件與設定位於來源子頁, 檢查未知來源, 完整位置, 最後更新時間, 唯讀 / 可編輯狀態, 格式驗證, 版本衝突與取消草稿
- 分開核對 LAM 連線與 Codex 最近活動證據, CPU 與已使用記憶體, GPU 型號 / 專用容量 / 共享上限 / 驅動版本. 閒置預設五分鐘, 可修改或停用, 輕量檢查發現新活動後恢復更新

- 核對活動保留天數的設定, 匯入與重啟保存, 舊版快取相容性, 六天前的 SQL / 網路 / MCP 活動與縮短天數後的過期移除. 時間範圍篩選與保存天數分別驗證
- 收合表格需顯示篩選後筆數, 時間摘要不能只依字串排序. 檔案操作紀錄置於表格區首位, modal 的導覽及追查按鈕靠近上方, 儲存操作留在編輯內容附近
- 同單位資料可共用多線折線圖, 各線有圖例, tooltip 與鍵盤讀值, 缺少樣本保留斷點. bytes 刻度使用 B / KiB / MiB / GiB, 檔案排行的短名稱需能區分同名位置, tooltip 保留完整路徑

- 核對各分頁卡片顯示設定的保存, 匯入, 取消與還原, 預設隱藏排行, 摘要數量與項目依全域及個別設定呈現, 隱藏卡片保留來源可用狀態. 驗證時間折線圖按個別技能, 工具, 網址, 網站, 檔案, 資料夾, MCP 與操作分類計數, 同一次操作的重複網址合併
- SQL, 網路與 MCP 保存筆數圖位於對應分頁, 省略平均值與百分位數. MCP 保存筆數顯示全部來源, 選取個別來源時隱藏. 保留已有圖表自訂設定, 圖表的 input 與下拉選單等寬
- 設定 switch 的文字與空白不切換狀態, 本體與鍵盤仍可操作. 追蹤全部 session 在更新或設定儲存後持續停用數量欄位與套用按鈕. 全部套用覆蓋個別數量或熱度前需確認, 取消不改變偏好
- 設定編輯器的折疊容器使用全寬, 篩選與操作按鈕可換行, 各模式表格標題正確, 桌面及窄螢幕無重疊. 來源紀錄 tag, 時間與子頁 / modal Tab 的間距沿用共用樣式

卡片庫變更需核對來源頁與總覽副本的參數獨立性, 隱藏卡片仍可從清單選用, 來源頁預設三張圖與四項主頁摘要, 子頁不設摘要. 摘要名稱及順序匯出後可還原, 每頁數量覆寫應保留. 內容預覽需檢查跨分頁的遮蔽, revision 變更, Markdown 連結及 HTML 文字, lazy loading 保留完整可取得內容

- 導覽維持總覽, 用量與額度, 對話, 專案, 工具, 資料操作, 錯誤與 Log, 監測程式八個主頁. 專案包含列表 / Git / 驗證, 工具包含呼叫與耗時 / MCP / 技能, 資料操作包含網路 / 檔案 / SQL. 檢查舊頁面入口, 排序, 圖表參數與匯入設定的相容性, 所有子頁沿用主頁範圍且可覆寫, 不顯示摘要設定
- Steam 配色為預設主題, 初次套用保留字級與資料設定, 之後保留使用者的主題 / 強調色選擇. 檢查深淺模式, 三種語言, 設定匯入, 狀態標籤與圖表多色, 不用色彩取代狀態文字
- 圖表與統計卡標題只顯示觀測主題, 不附加視圖名稱, 類別與圖表形式留在設定標籤及切換按鈕. 主頁與子頁 Tab 切換不主動捲動頁面, 明細視窗的 Tab 切換仍將內容捲回頂端
- 排程只讀取本機資料來源的名稱, 狀態, 執行時間與關聯 ID, 不保留 prompt 或帳戶 ID. 空資料與不可讀狀態分開顯示, 缺少對話關聯保留來源 ID, 不自行建立排程或補出未提供的執行結果
