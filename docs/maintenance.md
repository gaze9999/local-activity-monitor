# 維護與驗收

依實際修改選擇下列項目, 記錄版本 / diff, fixture, 執行方式與結果. 完成前回顧當次對話的追加需求, 不用靜態檢查代替實際介面或平台驗證

## 資料與觀察來源

- 沿 source -> collector -> API -> UI 追查新增與變更欄位, 核對來源健康狀態, 時間, 單位, 型別, 統計範圍, 去重及截斷. 來源未提供用 --, 已確認沒有事件 / 錯誤用無, 已確認數量為零用 0. 不用空白隱藏缺值, 不用未知掩蓋讀取失敗
- 對話檢查最新狀態, Model / Reasoning, 起訖時間, 分批歷史回補與 checkpoint. Skills 依 Thread / Call ID / Skill 去重, 更新與重啟不得重複加總或無故歸零. Token 不加總累計快照, 快取 Token 不再次加入總量
- MCP 檢查新來源自動出現, 自訂分類 / tag / 用途, 直接呼叫與 exec 辨識, 狀態 / 錯誤, 用量 / credits / 節省 / 瀏覽器 / 文件 / 驗證等來源提供的欄位. 未知來源沿用通用流程, 不依工具名稱假造指標或結果. 專有資料可加投影, 不另建一套設定或硬編碼 UI
- 紀錄開關由來源決定, 缺少來源功能時不提供假的開關. 啟動, 匯入及還原介面設定不自動改寫來源. 連線狀態只讀本機紀錄, 不用 paid API 或主動呼叫確認. 沒有觀測證據時省略連線 tag
- SQL 只辨識 literal 工具參數 / 程式碼及 SQL 診斷, 不執行來源. 操作數, 個別 SQL 耗時, 外層工具耗時, rows_affected / rows_returned 要分開. 內容明細綁定已觀察紀錄, 限量讀取, 遮蔽可辨識憑證, 不加入 snapshot 或保存 DB
- 錯誤與 Log 明細核對原因, 等級, code, Thread / Call / Request / Trace ID, 檔名 / 紀錄 ID, 關聯操作與來源狀態. 保留來源有提供的追查欄位, 不用一般內文字詞猜測失敗或回傳成功

## 介面與多國語言

- 同步 zh-TW, en, ja 的介面 / tooltip / 空狀態 / 按鈕與通知, 檢查 key 完整及變數 / 單位沒有被翻譯破壞. 實際切換語系, 主頁, 子頁, 設定與 modal 均需可操作. 台灣用語, 精簡文案與半形標點沿用上層指示, 不加入無關的排除式解釋
- 桌面及窄螢幕檢查長名稱, 大數值, 空資料與更新後的版面. 容器需可縮小, 多欄位置不因數值長度交換, 不同高度卡片可接續使用空間並維持欄位順序. 標籤 / 單位不出界, 卡片與頁面不產生無意義空區
- 主 / 子 Tab 不折行, 必要時在 Tab 列內捲動. 保留選取 / 鍵盤操作 / ARIA, 滑鼠 focus 不加多餘外框. 卡片與 Tab 拖曳直接操作元件, 預設關閉, 主頁與 modal 開關分開, 不能跨區移動, 順序需保存. 拖曳說明只在所屬區域的排序開關啟用後顯示
- 總覽預設依重要性選擇不同觀察項目, 同種圖表不重複預設顯示, 圖表與活動摘要分區. MCP 觀察來源在頂部四張摘要卡之後, 預設收合並保存選擇, 圖表 / 各來源摘要在表格之前. 所有排行預設前 5 項, 數量選擇放在卡片右上齒輪內, 表格仍涵蓋全部來源. 各來源摘要採相同半寬版面, 窄螢幕改單欄
- 圖表核對刻度, 單位, 圖例, tooltip, 超長標籤, 大數值, 狹窄卡片, 隱藏頁面再次顯示與不同語系. 標籤角度依可用空間決定, 同一圖表統一角度, 縮略要有完整 tooltip. 環圈總值可放圖外, 圓餅資訊另列. 平均 / P99 / P1 只用於有意義的分布, 分類與額度卡不加入耗時統計
- 表格預設每頁 10 筆與必要欄位, 篩選預設收合, 分頁 / 排序 / 搜尋 / 模型與狀態等篩選依實際資料有效. 介面字級預設 14 px, 放大後仍需檢查卡片 / modal / 控制項排版. 按鈕 / tag 有一致間距, Tag 以顏色區分狀態與分類且保留文字, Log 等級維持英文. 桌面橫捲只限表格容器, 窄螢幕資料卡保留欄位資訊
- 設定修改核對保存, 匯入預覽 / 取消, 全部還原預設, 整數正規化, 有變更才顯示還原, modal 內外拖曳開關分開. 通知不阻擋操作或改變排版. 關閉 modal 後原 tooltip 不得因 focus 返回而重新冒出
- 更新時間, 開啟時間與運行時間集中於右上角, 更新與更新頻率同行. 版本與標題分開, 來源說明只在使用資料的頁面顯示. 內部連結切換分頁後定位頁首或相關區塊, 不沿用前一頁的捲動位置
- 頁尾的詳細來源說明預設收合, 位置, 上限, 欄位與數量來自當次讀取結果. 未讀取或不可用需保留實際狀態, 不用固定檔名樣板或補零表示. 展開及切換子頁後應更新內容, 不追加掃描或讀取完整 payload

## 共用介面的設計依據

- 設定靠近相關內容, 基本選項先顯示, 詳細選項集中在齒輪. 依 [NN/g 的自訂介面指引](https://www.nngroup.com/articles/customization/) 與 [漸進式資訊展開](https://www.nngroup.com/articles/progressive-disclosure/), 保留可直接使用的預設, 不要求先自訂才能看到資料
- 來源的詳細位置與讀取結果使用可折疊區塊, 主要指標維持可見. 依 [GOV.UK Details](https://design-system.service.gov.uk/components/details/) 的用途區分主要內容與補充資訊, 摘要需清楚說明展開後可看到什麼
- 表格維持一致的工具列, 篩選與分頁, 桌面橫捲只在表格內. 參考 [Carbon Data table](https://www.carbondesignsystem.com/building-blocks/core/components/data-table/guidelines). 5 項排行, 10 筆表格與 14 px 字級是本專案的預設選擇

## 效能與交付

- 保持增量讀取, 分批回補, 白名單投影及既有檔案 / 行 / bytes / rows / 事件保存上限. 一般 refresh 不讀完整 payload, Skill 文件或任意檔案, 詳細內容按需讀取. 不為來源連線狀態加入探測或額度消耗
- 同一 fixture 比較冷啟動與後續更新, 檢查讀取量, CPU / 耗時, HTTP / 壓縮大小及 DOM 更新. 切換頁面, 隱藏瀏覽器, 篩選, modal 與大型資料集不得觸發無必要重掃或累計重算
- focused unittest 驗證資料及 endpoint 邊界, 實際服務頁面驗證 JS / CSP, console / network, 設定, 互動與排版. 新增來源 / 多種格式需要 fixture, 不從範例測試推論正式 provider 已驗證
- release 檢查版本一致, wheel / sdist / 原生套件包含完整 web assets, 語系, runtime 與授權文件, 多平台啟動及 loopback / 檔案邊界, CI 狀態與產物 checksum. 未驗證平台或失敗工作要明確列出
