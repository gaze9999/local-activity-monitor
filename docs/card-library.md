每個 Tab 的右上設定提供同一份卡片選擇介面, 依資料來源分類, 列出卡片類別, 可用圖表形式與個別設定. 總覽可選用所有來源圖表, 每個實例保留自己的參數

趨勢與比較卡的統計放在獨立卡片, 顯示 P99、平均值、總數及樣本數. 資料整理耗時與整理 CPU 時間省略總數, 對應的總覽副本與自訂統計來源沿用相同規則, 原有樣本數來源 ID 保留. 工具與 SQL 等實際執行耗時保留加總. bytes 取樣卡使用樣本數. 保存筆數卡省略統計指標

主摘要預設四項重要指標, 全域及個別主頁可調整數量, 副標優先顯示次要記錄值. 子頁摘要預設隱藏, 已提供的摘要區可從設定選用. 已提供的指標可選擇, 排序與改名, 缺少資料維持 --. 總覽預設顯示 Model, 對話, 錯誤與用量, 其餘卡片保留選用入口

新增圖表沿用 cardLibrary 的來源及類別定義, 共用 bars, timeline, categoryTimeline 或 activeThreadsTimeline, 不另建立一套設定保存或讀取流程. 摘要指標依來源區域及序號識別, 原有序號保留, 新指標加在尾端. 每個卡片的識別碼與參數可匯出 / 匯入

圖表分類色隨主題及明暗模式調整, 保留標籤、數值與 tooltip 讀值, 多線圖另用線型區別. 卡片更新時間靠右, 說明及時間縮小, 統計數值維持一般字級

## 來源、自訂卡片與群組

摘要設定可替內建指標選擇資料來源, 或新增有穩定 ID 的數值卡片. 卡片庫與總覽活動摘要也可新增數值卡、命名群組及指定卡片所屬群組, 來源選單包含已提供的摘要、卡片欄位、圖表統計及表格數值. 已確認的 0 保留, 缺值顯示缺值

自訂卡片的名稱、來源、顯示及順序各自保存. 群組移動既有卡片節點, 保留表格 / 圖表 instance、焦點及監聽器, 移除群組後成員回到未分組. 設定列以左側勾選框控制顯示, 握把可拖曳, 聚焦後以方向鍵、Home / End 排序, Escape 取消, 不在保存資料時重新產生 ID

群組標題可拖曳、鍵盤排序及收合, MCP 來源摘要歸入「活動摘要」. 群組移動後的更新仍沿用原卡片

表格來源提供平均值及最新值, 可加總的次數與執行耗時另提供總和, 使用目前篩選條件下全部已載入資料, 不限當頁. 百分比、速率、平均值、P99、效能診斷樣本與程序累計值不提供總和. 平均值只計算有效數值, 缺值不算零. 最新值取最近活動或事件時間的那筆紀錄, 無時間欄位時使用原順序第一筆, 該欄缺值顯示 `--`. ID 欄位不列為數值統計來源, 已保存但不再提供的來源保留選擇及 `--`, 不改讀其他欄位

初次進入使用整個卡片容器的單一載入狀態, 完整快照到達後切換成卡片內更新. 已取得的初始目錄可先顯示, 其他資料維持等待狀態. 兩種結構共用 WBUI `createDataState`, LAM 的 `createLoadingScope` 提供 `setScope('container'|'cards')`, `setState` 與 `destroy`, `setLoadingScope` 統一切換各頁. 容器模式停用卡片內載入效果, 切換不重建卡片、資料或偏好

摘要的 `sources` / `custom` 與卡片的 `cardLayouts` 保存格式及上限見[設定檔格式](settings-format.md). 主題 / 動畫 / 直向布局沿共用 tokens 與元件, LAM 擁有來源、群組意義與偏好. 介面與驗收入口見[使用說明](usage.md)、[驗證紀錄](validation.md)及[AI 入口](../AI.md)
