# 共用卡片庫

每個 Tab 的右上設定提供同一份卡片選擇介面, 依資料來源分類, 列出卡片類別, 可用圖表形式與個別設定. 總覽可選用所有來源圖表, 每個實例保留自己的參數

| 來源 | 可用卡片 | 圖表形式 |
| --- | --- | --- |
| 對話 | 活動趨勢, 模型分布, 執行環境分布 | 折線 / 長條, 橫條 / 直條 / 圓餅 / 環圈 |
| 工具 | 呼叫趨勢, 工具比較, 呼叫耗時, 次數排行 | 折線 / 長條, 排行可用橫條 / 直條 / 圓餅 / 環圈 |
| Skills | 讀取趨勢, 技能比較, 活躍對話, 次數排行 | 折線 / 長條, 排行可用橫條 / 直條 / 圓餅 / 環圈 |
| Git / 驗證 | 操作趨勢, 操作比較, 活躍對話, 操作分布 | 折線 / 長條, 分布可用橫條 / 直條 / 圓餅 / 環圈 |
| 網路 | 活動趨勢, 網址 / 網站比較與排行, 保存筆數 | 折線 / 長條, 排行可用橫條 / 直條 / 圓餅 / 環圈 |
| 檔案 | 活動與路徑比較, 檔案 / 資料夾排行, 讀寫次數 / bytes / 大小排行 | 折線 / 長條, 排行可用橫條 / 直條 / 圓餅 / 環圈 |
| MCP | 呼叫趨勢, 來源比較, 操作 / 來源分布, 保存筆數 | 折線 / 長條, 分布可用橫條 / 直條 / 圓餅 / 環圈 |
| SQL | 操作趨勢, 操作比較與分布, 保存筆數 | 折線 / 長條, 分布可用橫條 / 直條 / 圓餅 / 環圈 |
| 錯誤 / Log | 活動趨勢, 等級 / 類型比較, 來源分布 | 折線 / 長條, 分布可用橫條 / 直條 / 圓餅 / 環圈 |
| 用量 | 模型 Token, 帳戶用量與額度 | 橫條 / 直條 / 堆疊直條 / 圓餅 / 環圈, 額度使用來源比例 |
| 監測 | 裝置使用量, 整理 / CPU 耗時, 資料保存與讀取量 | CPU / RAM bar, 折線 / 長條 |
| My dots | 產出類型 | 橫條 |

趨勢與比較卡的統計放在獨立卡片, P1 / P99 合併呈現, 另列平均值, 總數及統計範圍. bytes 取樣卡使用樣本數. 保存筆數卡省略統計指標

主摘要預設 4 張, 子摘要預設 3 張, 全域及個別頁面可調整數量. 已提供的指標可選擇, 排序與改名, 缺少資料維持 --. 總覽預設顯示 Model, 對話, 錯誤與用量, 其餘卡片保留選用入口

新增圖表沿用 cardLibrary 的來源及類別定義, 共用 bars, timeline, categoryTimeline 或 activeThreadsTimeline, 不另建立一套設定保存或讀取流程. 摘要指標依來源區域及序號識別, 原有序號保留, 新指標加在尾端. 每個卡片的識別碼與參數可匯出 / 匯入
